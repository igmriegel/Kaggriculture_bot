# Agent workflow

1. Read `AGENTS.md` and the task route in `docs/README.md`.
2. Read only the required domain documents before editing.
3. Locate the catalog entry and tests for every public harness structure changed.
4. Update the catalog, extension guide, decision log, or backlog as applicable.
5. Run pre-commit, documentation validation, and relevant tests.
6. Inspect the diff and create one semantic, atomic commit.

## Handoff

Report the contract changed, implementation and tests affected, validation
results, known limitations, and commit hashes.
